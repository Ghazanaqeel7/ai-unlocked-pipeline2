Safe Deployment Guide

How to Transfer to Vercel Without Affecting Anything Else

Updating only docs/index.html keeps docs/dashboard.html, docs/vault.html, and all pipeline scripts/workflows untouched.

  1. STEP 1 · COPY SOURCE

    Click Copy docs/index.html in the header or drawer and paste it into docs/index.html inside your repository.

  2. STEP 2 · COMMIT ONLY INDEX

    Stage and push only docs/index.html. Your dashboard, vault, and automation scripts remain completely isolated.

  3. STEP 3 · VERCEL ROOT = docs

    In Vercel Project Settings, confirm Root Directory is set to docs so Vercel serves the updated landing page cleanly.
